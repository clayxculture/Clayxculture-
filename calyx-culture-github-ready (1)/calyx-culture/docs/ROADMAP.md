# Roadmap (not built yet, in the order we suggest)

1. Bot protection (Cloudflare Turnstile) and per-IP limits through an edge function that places orders.
2. Per-size stock (variants), size charts, multi-photo gallery.
3. Online payments (Razorpay test mode first): server-created payment, verified webhook, reconciliation, refunds.
4. Instant owner alerts (Telegram) for new and held orders, with retry.
5. Claims and exchange system matching the Returns policy, pack-out evidence, grievance tickets, deadlines.
6. Admin roles (owner and staff), second lock in front of /admin (Cloudflare Access), masked exports.
7. Courier integration, COD remittance matching, bills of supply with numbering.
8. Self-hosted fonts and a data-saver mode for slow connections.
9. Dynamic sitemap and per-product share previews.
